## What it does
In Mists of Pandaria Classic the **Leave Instance Group** option does not show up in the player frame menu. This addon makes it appear whenever you are in an instance group (for example one formed by the Dungeon Finder) and asks for confirmation before leaving.

## Features
- Shows **Leave Instance Group** in the right-click menu of your player frame while you are in an instance group.
- A Yes/No confirmation popup before leaving, so you don't drop out by accident.
- The popup closes with Escape.
- Translated to the main client languages.

## Installation
1. Download the zip from the [latest release](https://github.com/Pirson-s-Addons/LeaveInstanceGroup/releases/latest) or from [CurseForge](https://www.curseforge.com/wow/addons/leave-instance-group).
2. Extract the `LeaveInstanceGroup` folder into `World of Warcraft/_classic_/Interface/AddOns/`.
3. Restart WoW and enable the addon.

## Usage
- Right-click your player frame, choose **Leave Instance Group** under *Other Options* and confirm.
- There are no slash commands or settings.
